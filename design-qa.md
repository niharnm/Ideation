# Design QA

## Target and implementation

- Reference direction: Egoist AI Passport at `https://ego.ist/`.
- Implementation: Handshake claimant request at `http://127.0.0.1:4181/`.
- Intent: translate the sparse editorial framing, kinetic type, generous whitespace, and restrained motion into the existing consent flow without copying Egoist copy or structure.

## Visual pass

- The opening message uses staged word entrance, with the supporting content following in sequence.
- The request uses a near-white field, dark pill action, compact status signal, and calm product copy.
- An original ingredient-passport illustration sits in the permission flow. Its drift animation and a quieter scope-card animation are disabled for people who request reduced motion.
- The actual constraint selection updates the scope signal and expiry card immediately.

## Functional pass

- Checkbox changes, sentence-driven passport updates, duration changes, and the approval path were checked in the in-app browser.
- The local approval path completed successfully and showed the active access receipt.
- Browser console reported no errors during the checked paths.
